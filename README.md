# ⌨️ KeyFix

KeyFix is a lightweight Linux tool that converts text typed with the wrong keyboard layout into the characters you actually intended.

## ✨ The Plan

- 🔄 **Layout Correction** — Convert text between Persian and English keyboard layouts.
- ⚡ **Live Typing** — Correct input as you type.
- 🖥️ **Terminal First** — Start with Bash and Guake, then expand to other environments.
- ⚙️ **Your Setup, Your Rules** — Choose where KeyFix is enabled through a future settings interface.

## 🛠️ Roadmap

- [ ] Build the layout conversion engine
